# ML-2.2 — declared absent

**The estate has never held the text of Maher's License version 2.2.**

[ML-2.3](ml-2-3.md) declares that it supersedes ML-2.2, and the superseded fourteen-harm register
links here. No copy of ML-2.2 was ever supplied to or published by this estate. The
[version history §3](version-history.md) records the gap; [AG-004 AR-01](../agents/ag-004-refusal-and-escalation-register.md)
records the refusal to write a plausible reconstruction, because fabricating a superseded licence
inside the instrument that defines *Ṣidq* would be the worst available breach.

**What a reader should do.** Treat any citation to ML-2.2 as a citation to an unpublished text.
For the current rules, read [ML-2.3](ml-2-3.md). For the last published predecessor, read
[ML-2.1](ml-2-1.md).

**What would close this.** The Curator either publishes the ML-2.2 text he holds, or rules that
ML-2.3 is re-based onto ML-2.1 — [RAT-14](../00-governance-map/open-questions-and-ratifications.md#rat-14--does-ml-22-exist).
