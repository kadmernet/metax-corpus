# AG-019 · Human-in-the-Loop Gates

> **Authority.** `governing`, tier 4. Review and audit of agent output: [AG-011](ag-011-agent-review-and-audit.md).

> **Disclosure first.** Of the nine gates, the estate has passed **none** with a named human
> recorded in a provenance stamp ([AG-016](ag-016-output-contract-and-provenance.md)). The
> repository holds ~130 agent-drafted instruments that have crossed no gate. They are not
> published, which is why no gate has yet been breached.

---

## 1. Position

"Reviewed by an agent" is not a gate and is never recorded as one. A gate is the point at which a
**named person** accepts responsibility for an artefact moving.

## 2. The nine gates

| # | Gate | Named human required |
|---|---|---|
| 1 | Publication of any page | Curator or delegate |
| 2 | Any credential decision | Assigned reviewer(s) |
| 3 | Any moderation sanction | Moderator |
| 4 | Any academy status change | Curator + audit record |
| 5 | Any Determination | Steward |
| 6 | Any change to a governing document | Curator (+ ethics reviewer for §0.4/§0.5) |
| 7 | Any correction entering the Corrections Log | Curator |
| 8 | Any Arabic term entering the Lexicon as settled | Curator (+ Arabic reviewer) |
| 9 | Any claim moving from `[VERIFY]` to sourced | Person who read the source |

## 3. Mechanism

The human is named in the provenance stamp (`accepted_by`). The gate is **the stamp**, not the
conversation. An instruction to write something is not acceptance of what was written.

## 4. Worked instance

The Curator instructed this session to generate missing documents. That satisfies no gate for the
documents generated. Gate 6 applies to each new governing instrument; until accepted, each is a
**draft in fact** regardless of its `status:` field. [GM-15](../00-governance-map/corpus-review-v2026.10.2.md)
recommends a `status: draft` sweep (refinement F-04).

## 5. Failure modes

Rubber-stamp acceptance of forty files at once; gate 9 satisfied by the drafting agent.

## 6. Limits

A gate assigns responsibility; it cannot ensure the human read the artefact.

## 7. Falsifier

Wrong if an artefact passes a gate whose named human can show they never saw it.

## 8. Obligation

Before any publication, accept or reject each instrument individually, and record it.

## 9. Macro register

"Human in the loop" is often a legal fig leaf over automated decisions. This list makes it a
specific, countable claim — **which human, which decision, recorded where** — so the phrase can
be falsified.
