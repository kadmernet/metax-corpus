## 4. Conflicts recorded

1. **S37's status cell reads "S38"** in the source, which is a transcription fault; its Bridge
   cell is empty. Carried verbatim. See R-59.
2. **REG-01 uses unpadded `S1`, `S2`, `S3`** for *different* series (for example *Understanding
   Before Use*). These collide with this canon's `S01`–`S50`. Under ST-01 both are published.
   Which one is `S1` is a Curator question: [RAT-27](../00-governance-map/open-questions-and-ratifications.md#rat-27).
3. The source registry reserves number blocks by meaning (S051–S099 Branch B, S100–S149 operator
   domains, S150–S199 Branch D continuation). This conflicts with ST-01 Rule 1, which forbids
   numbers chosen for meaning. See R-60.
4. The source Charter §0.2 says **"fifty-two series across five branches"**. The table has 52
   rows (F1, F2, S01–S50), so the figure **agrees** with the canon. It is still a typed count in
   a charter, and under [R-21](../00-governance-map/reconciliation-ledger.md) it should be computed
   from these rows. It becomes false as soon as a series is added, and nothing would flag it.
   *(Corrected during drafting: an earlier version of this note wrongly said the counts
   disagreed.)*
