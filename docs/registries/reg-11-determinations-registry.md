# REG-11 · Determinations Registry

> **Authority.** A **record**. The procedure is [ML-OPS-3](../license/determinations-procedure.md).
> ML-2.1 Part D and ML-2.1 §D.4 require every Determination to be published here with its reasons.
> [MX-016](../corpus/mx-016-appeals-and-due-process.md) and [ML-2.1](../license/ml-2-1.md) cite this
> register as "REG-07"; that number now belongs to Defect Classification ([GM-13](../00-governance-map/identifier-reallocation-record.md)).

> **Disclosure first.** **Zero Determinations.** No request has been filed, and no licence has
> been evaluated.

## 3. Evaluated-licenses list

## 4. Rules

- Negative and withdrawn Determinations are published with the same prominence as positive ones.
- A Determination with no published reasons is void (ML-OPS-3 §3).
- Rows are never deleted. A Determination later voided under §G.5 keeps its row, marked void.

## 5. Falsifier

This register is wrong if a Determination has been issued anywhere that does not appear here.
